# Data

Public datasets are **not** stored in git.

Place local downloads here (or in the paths expected by the scripts):

- PatchCamelyon HDF5 splits after extraction
- CAMELYON17-WILDS packs and derived `*_x.h5` / `*_y.h5` files
- Preprocessed outputs from `scripts/preprocess_histopath_h5.py`

See the root [`README.md`](../README.md) for download pointers. Large archives are ignored by `.gitignore`.
